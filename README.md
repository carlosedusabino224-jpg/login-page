# Página de Login

Projeto desenvolvido no Dia 6 da minha sequência de projetos diários.

A ideia foi criar uma página de login simples utilizando HTML e CSS, com campos para e-mail e senha e um botão de envio.

## Tecnologias utilizadas

- HTML5
- CSS3

## Funcionalidades

- Campo para e-mail
- Campo para senha
- Validação dos campos obrigatórios
- Botão de envio
- Efeito visual ao passar o mouse no botão
- Efeito de foco nos campos

## Como executar

1. Baixe ou clone o projeto.
2. Abra a pasta do projeto.
3. Abra o arquivo `login.html` no navegador.

## Objetivo

Praticar a criação de formulários em HTML e estilização utilizando CSS.

Projeto feito como parte da minha sequência de projetos diários.
